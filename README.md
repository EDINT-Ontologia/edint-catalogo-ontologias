# Catálogo de Ontologías EDINT

[![Licencia](https://img.shields.io/badge/licencia-CC%20BY--SA%204.0-lightgrey)](LICENSE)
Catálogo de ontologías EDINT para infraestructuras urbanas inteligentes, orientado a la interoperabilidad semántica y alineado con iniciativas de datos abiertos (FEMP, datos.gob.es).

## Financiación (Funding)

Este catálogo ha sido desarrollado en el contexto del Espacio de Datos para las Infraestructuras Urbanas Inteligentes ([EDINT](https://edint.es/)).
